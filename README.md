# Kiếm Hành — Demo 1

Game 2D RPG kiếm hiệp chạy trực tiếp trên trình duyệt.

## Chơi
Mở `index.html`.

## Điều khiển
- Điện thoại: nút ◀ ▶ ⬆ ⚔
- Máy tính: A/D hoặc ←/→, W/Space để nhảy, J/Enter để đánh.

## GitHub Pages
Upload `index.html` lên repository và bật Pages với source là branch chứa file này.
