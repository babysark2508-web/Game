# Shadow Blade — GitHub Pages

Game platform 2D chạy trực tiếp trên trình duyệt, không cần server hay thư viện ngoài.

## Điều khiển
- Điện thoại: nút ◀ ▶ ⬆ ⚔
- PC: A/D hoặc ←/→, Space để nhảy, J để đánh.

## Đưa lên GitHub Pages
1. Upload `index.html`, `style.css`, `game.js` vào thư mục gốc repository.
2. Commit changes.
3. Vào **Settings → Pages**.
4. Chọn **Deploy from a branch**.
5. Branch: `main`, folder: `/ (root)`.
6. Save.
7. Chờ GitHub build xong rồi mở đường dẫn Pages của repository.

Game không dùng ảnh/nhạc bên ngoài nên phù hợp GitHub Pages.
